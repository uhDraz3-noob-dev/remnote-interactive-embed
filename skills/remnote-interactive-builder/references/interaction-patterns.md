# Interaction pattern selection

Use the pattern that makes the learning objective visible and, where useful, explorable or manipulable. Choose by the relationship being taught, not the topic name. This table suggests possibilities, not mandatory templates.

| Concept structure | Preferred interaction | Learner action |
| --- | --- | --- |
| Causes, variables, or tradeoffs | Causal map or manipulable model; simulation when quantitative change matters | Trace a consequence, alter the represented object, or adjust an accessible control and observe downstream effects |
| Ordered mechanism or pathway | Step explorer | Move through stages and inspect what changes at each transition |
| Hierarchy, categories, or connected ideas | Simple or expandable concept map | See the organization at a glance; expand a branch or trace labeled relationships when useful |
| Similar items that are confused | Comparison lab | Toggle cases or criteria and see differences highlighted |
| Conditional reasoning or diagnosis | Branching scenario | Choose an action and receive causal feedback, with a restart path |
| Spatial system or anatomy | Labeled diagram, cutaway, or spatial explorer | Select structures, reveal a layer, or manipulate a relevant structure; use 3D only if depth matters |
| Equation or quantitative relationship | Visual calculator | Change inputs and see the equation, units, and visual result update |
| Threshold, spectrum, or continuum | Continuum explorer | Move a control and inspect boundary cases and transitions |

For mind maps, use hierarchy for categories, directed arrows for cause and effect, and labeled links for other relationships. Do not automatically turn every topic into a center bubble with spokes. Keep essential connections visible; expansion should reveal useful detail rather than hide the entire explanation. Avoid generic flip cards when a structural interaction is possible. Avoid force-directed physics for mind maps: a stable responsive SVG or CSS layout is more usable on phones and inside an iframe.

## Calibrate depth

- **Simple:** a clear map, labeled diagram, or comparison may already expose the relationship. Add only purposeful selection or expansion, not a simulation to make it look advanced.
- **Explorable:** use selectable structures, branches, layers, or manual stages when attention and sequence matter.
- **Manipulable:** let the learner change an object or variable when seeing the consequence teaches the objective.
- **Simulated:** coordinate time and interacting variables only when dynamic behavior matters and a defensible model is available.

For example, heart anatomy may call for a cutaway, the order of blood flow for a traceable path, and ventricular volume change for a deforming chamber. A heart-related classification may need only a small hierarchy. None of these is inherently a better or more creative design than the others.

Do not make visual richness depend on added mechanisms: a polished simple map can be sufficient, and a detailed illustration can teach one relationship. Prefer meaningful shape, position, connection, movement, or highlighting over a dashboard of explanatory boxes. Keep numbers and text where they clarify, without treating their elimination as a goal.

For complex concepts, combine linked patterns around one shared state and learning objective. Reveal secondary controls progressively. A simulation can coordinate a diagram, graph, scenario selector, and prediction check when each supports the concept; avoid adding unrelated features merely to increase interaction count.
